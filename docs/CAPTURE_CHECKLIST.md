## 🎨 Screenshot Capture Best Practices

### General Tips:
1. **Browser Setup:**
   - Use Chrome or Firefox (best for screenshots)
   - Maximize browser window
   - Hide bookmarks bar (F11 for fullscreen)
   - Clear any browser extensions that clutter UI

2. **Resolution:**
   - Use 1920x1080 or higher resolution
   - Ensure text is readable when zoomed
   - Consider retina displays (2x resolution)

3. **Privacy:**
   - Blur or replace any real email addresses
   - Use placeholder names if needed
   - Remove any personal information visible

4. **Quality:**
   - Ensure images are clear and not pixelated
   - Use PNG for screenshots (better quality)
   - Compress if files are too large (>1MB each)

5. **Consistency:**
   - Use same browser for all screenshots
   - Use same theme (light or dark) for consistency
   - Ensure all screenshots show completed/polished features

### Capture Tools:
- **Windows:** Snipping Tool, Windows + Shift + S
- **Mac:** Cmd + Shift + 4, or use built-in screenshot tool
- **Browser Extensions:** 
  - Full Page Screen Capture (for long pages)
  - Awesome Screenshot (for annotations)
- **Online Tools:** Canva, Figma (for editing)
